BALI TARANTULA ATV — MODERN HOMEPAGE UPDATE

This package is based on the existing Bali Tarantula Adventure PHP Native project archive.

WHAT CHANGED
- Updated homepage-only visual theme to extreme adventure: red, black and white.
- Restyled hero, calls to action, package cards, story, features, statistics, reviews, gallery and closing CTA.
- Updated default hero copy for Bali Tarantula ATV. Admin-managed homepage content still takes priority.
- Kept existing PHP queries, database schema, package links, booking link, admin homepage controls, gallery, reviews, SEO metadata, hero slider/video, and booking/payment system files unchanged.
- CSS overrides are scoped to the homepage to reduce impact on inner pages.

INSTALL
1. Make a backup of the live website files and database first.
2. Upload the included project files to a staging copy of the website first.
3. Replace the website root index.php with this package's index.php. The archive includes the current source snapshot for testing; do not overwrite newer production files wholesale if the live project has changed since this snapshot.
4. Open Admin → Homepage and review the saved hero title/text. Existing saved values override the new fallback copy.
5. Test homepage, package detail, booking, payment, admin login, and mobile layout before deploying.

This is a source-code update; it has not been deployed to the live website.
