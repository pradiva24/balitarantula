# Bali Tarantula Adventure

Responsive homepage concept for Bali Tarantula Adventure using a bold black-and-orange extreme-adventure visual direction.

## Current scope

- Static frontend homepage
- Responsive mobile navigation
- Adventure cards for ATV, rafting, and jungle experiences
- Brand introduction, reasons to choose us, and booking CTA
- CSS and JavaScript kept in separate asset files

## Project structure

```
index.html
assets/
  css/
    style.css
  js/
    main.js
```

## Preview locally

Open `index.html` in a browser. For a local development server, use the Live Server extension in VS Code.

## Before launch

1. Replace the placeholder WhatsApp URL `https://wa.me/` in `index.html` with the official business number, using international digits only.
2. Replace stock photography with approved Bali Tarantula Adventure images.
3. Confirm package names, descriptions, pricing, contact details, and booking destinations.
4. Check that third-party image and Google Fonts requests are acceptable for the production site.

## Next phase

Connect the approved frontend to PHP Native templates and add MySQL/PDO-backed package and booking functionality in a separate implementation phase.
